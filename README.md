# 减脂增肌记录小程序

微信原生小程序 MVP，用于记录减脂增肌期间的每日打卡、力量训练、坡度快走和趋势复盘。

## 技术栈

- 微信原生小程序
- TypeScript
- WXML / WXSS
- 本地存储 `wx.setStorageSync`

第一版暂不接云开发，先跑通核心体验。后续可以把 `utils/storage.ts` 替换为云数据库读写。

## 页面

- 今日：显示当天训练安排和近14天概览
- 打卡：记录体重、腰围、步数、睡眠、饮水和饮食完成度
- 训练：记录全身力量训练动作、重量、次数
- 坡度快走：记录时间、速度、坡度和疲劳程度
- 复盘：显示近14天趋势和调整建议
- 我的：维护个人目标和基础资料

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前 `miniprogram` 文件夹。
4. AppID 可以先使用测试号或游客模式；正式发布前替换 `project.config.json` 里的 `appid`。
5. 编译运行。
